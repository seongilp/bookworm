# 책벌레 문장수집 — 프론트엔드

Nuxt 3 + Tailwind CSS v4 + shadcn-vue 스타일 컴포넌트(reka-ui). 토스풍 미니멀 UI.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # 프로덕션 빌드
node .output/server/index.mjs   # 프로덕션 미리보기
```

백엔드 주소는 `NUXT_PUBLIC_API_BASE` 환경변수로 바꿀 수 있습니다 (기본: `http://localhost:8000`).

자세한 내용은 루트 [README](../README.md) 참고.
